# Paraboloids

Minimal front-end web app to explore paraboloids (no frameworks). Current stage shows colored axes and a subtle XY plane grid.

How to run:

- Open `index.html` in a browser (Chrome/Edge/Firefox). No build step.
- Rotate: left mouse, Zoom: wheel, Pan: disabled (by design to keep it simple).

Notes:

- Axes colors follow Three.js convention: X red, Y green, Z blue. Only the XY plane grid is visible to reduce clutter.
